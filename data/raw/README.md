# data/raw

Đặt các sổ điểm `.xls` xuất từ phần mềm sổ điểm vào đây (không đưa lên git vì chứa thông tin cá nhân học sinh).

Mẫu tên tệp: `KHOI 6 -22-23.xls` (cả năm), `KHOI 6-HK1-22-23.xls`, `KHOI 6-HK2-22-23.xls`. Loại sổ được nhận diện từ tiêu đề sheet.

Sau đó chạy `scripts\prepare_data.bat` rồi `scripts	rain.bat`.
